Design intent

Scribe is a native, local-first transcription utility. Its task hierarchy is: confirm the selected local model, start or stop listening, then edit/copy the transcript. Models, Playground, and Settings are secondary task pages, not dashboard destinations.

Layout

Primary native window: 1100x760
Minimum native window: 840x600
Rail: 60 logical px (selected compact icon rail)
Workspace gutter: 24 logical px
Panel gap: 16 logical px
Panel radius: 10-12 logical px
At minimum size: wrap dense rows and maintain a single main column.

Token roles

  • Glass shell: translucent only when system compositing remains legible; fall back to solid quiet surface.
  • Scribe Blue: only primary action, focus, selected navigation, and progress.
  • Inset depth: listening well and selected navigation only. Panels use a hairline and near-flat elevation.

State contracts

  • Transcribe supports ready, setup-required, recording, stopping, transcribing, completed, and insertion-error states without discarding transcript content.
  • Transcript Clear is immediate in the current product; this visual branch does not add confirmation.
  • Model actions reflect actual install/runtime state. Runtime maintenance remains collapsed.
  • Playground selection is drafted until Apply, can be empty, and is locked during an active run.
  • Settings save immediately with quiet inline confirmation.

Accessibility and egui constraints

  • Visible 2 px focus outline; keyboard order follows the visual order; icon-only actions need names/tooltips.
  • Use `available_width`, wrapping layouts, `ScrollArea`, and non-overlapping vertical fallbacks. Do not use web-specific CSS assumptions in egui.
  • egui 0.27 has no native focus-trap primitive. The chooser uses a pointer shield, initial focus, Cancel/Escape, and opener focus restoration.
  • Native backdrop blur is optional; use translucent fills with a solid fallback.
  • Operational progress may animate with text; decorative perpetual motion is banned. Reduced-motion control is a later follow-up.

Acceptance criteria

  • At 1100x760, Transcribe shows compact rail, context, listening control, and transcript without scroll clipping.
  • At 840x600, all content remains readable and interactive without horizontal scroll.
  • No fake metrics, cloud/account language, generic dashboard cards, glow effects, or decorative illustrations.
  • Every unavailable/disabled action explains the local next step near the control.
