## Local-first means a narrow boundary

Scribe has no cloud speech-to-text service, account, synchronization service, or plugin system. The normal GGUF path has no Python, localhost server, downloaded runtime package, or inference executable. Private legacy adapters remain for configuration/artifact migration and are not the normal UI path. An installed selected model may be loaded during startup integrity/health validation. Microphone PCM, preparation, VAD, preview, and final decoding remain in native workers; tentative text is never sent to another application.

Need help with a local runtime, hotkey, clipboard, or platform issue? Start with <a href={`${base}troubleshooting/`}>Troubleshooting</a>.

The detailed implementation reference remains the [repository README](https://github.com/tyhuang9/scribe/blob/main/README.md). For the current scope and source references, use <a href={`${base}project-status/`}>Project status</a>.
